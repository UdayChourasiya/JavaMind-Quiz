# JavaMind Quiz - AI-Powered Java Quiz Application

A Spring Boot web application that uses **Spring AI** with a locally hosted **Ollama (llama3.2)** model to generate fresh Java True/False questions every session. No question bank is stored: every quiz is generated by the AI on the fly.

## Features

- Generates **5 new Java True/False questions** each time a session starts
- One-question-at-a-time flow with a clean, responsive UI
- Structured prompt that forces the model to reply in strict JSON, which is parsed into Java objects using Jackson
- Per-user question flow, answers and score managed with `HttpSession`
- Color-coded results table showing correct vs. wrong answers and the final score

## Tech Stack

- **Java**, **Spring Boot**, **Spring MVC**
- **Spring AI** (`ChatClient`)
- **Ollama** running `llama3.2` locally
- **Thymeleaf**, **HTML**, **CSS**
- **Jackson** (JSON deserialization)
- **Maven**

## How It Works

1. The controller asks the `ChatClient` for 5 Java True/False questions using a structured prompt.
2. The model's JSON response is deserialized into `Question` objects with Jackson.
3. Questions, the user's answers and the score are stored in `HttpSession`.
4. Thymeleaf pages show one question at a time, then a final results table.

## Prerequisites

- JDK 17 or higher
- [Ollama](https://ollama.com) installed and running
- The `llama3.2` model pulled locally:
  ```bash
  ollama pull llama3.2
  ```

## How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/UdayChourasiya/JavaMind-Quiz.git
   cd JavaMind-Quiz
   ```

2. **Make sure Ollama is running** with `llama3.2` available.

3. **Start the application**
   ```bash
   mvnw spring-boot:run
   ```

4. **Open the app** in your browser (default port):
   http://localhost:8080
